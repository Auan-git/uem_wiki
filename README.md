## 功能特性

- **Wiki风格导航** - 左侧全局导航栏，快速切换板块
- **文章目录** - 右侧自动生成TOC目录，支持滚动高亮
- **全站搜索** - 支持关键词搜索所有文章
- **返回顶部** - 长文章快速回到顶部
- **评论互动** - 每篇文章支持评论交流
- **响应式设计** - 支持手机、平板、电脑浏览

## 如何使用

1. **浏览内容**：点击顶部导航栏或左侧边栏进入各板块
2. **搜索信息**：使用右上角搜索框快速定位内容
3. **评论交流**：在文章底部评论区分享你的经验
