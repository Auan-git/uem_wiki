## 💡 体育课建议

1. **选擅长的**：选择自己相对擅长的项目
2. **考虑兴趣**：选感兴趣的项目更容易拿高分
3. **注意时间**：体育课时间要和课表协调
4. **了解教师**：不同教师评分标准可能不同

## 📊 体测项目

| 项目 | 男生标准 | 女生标准 |
|------|----------|----------|
| 1000米/800米 | ≤4'30" | ≤4'00" |
| 引体向上/仰卧起坐 | ≥10个 | ≥25个 |
| 立定跳远 | ≥2.10m | ≥1.50m |
| 坐位体前屈 | ≥3.7cm | ≥4.2cm |

> 注：以上为参考标准，具体以学校规定为准
