# 体育课选择

> 选择适合自己的体育课，让体育课成为大学生活的乐趣

| 项目 | 难度 | 推荐指数 | 说明 |
|------|------|----------|------|
| 篮球 | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 热门，需要一定基础 |
| 足球 | ⭐⭐⭐ | ⭐⭐⭐⭐ | 团队运动，氛围好 |
| 羽毛球 | ⭐⭐ | ⭐⭐⭐⭐⭐ | 上手快，适合女生 |

| 太极拳 | ⭐ | ⭐⭐⭐ | 简单，适合不想太累的 |
| 游泳 | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 实用技能，但需会游泳 |
| 田径 | ⭐⭐⭐⭐ | ⭐⭐⭐ | 较累，但锻炼效果好 |

## 💡 选择建议

### 按基础选择
- **零基础**：乒乓球、太极拳、健美操
- **有一定基础**：羽毛球、篮球
- **运动达人**：足球、游泳、田径

### 按目标选择
- **想拿高分**：乒乓球、太极拳（评分标准相对宽松）
- **想锻炼身体**：篮球、足球、田径
- **想学技能**：游泳（实用性强）

### 按时间选择
- **早上有课**：选择上午的体育课
- **下午有课**：选择下午的体育课
- **想周末锻炼**：选择周末班（如有）

## ⚠️ 注意事项

1. 选课时注意时间冲突
2. 部分项目有身体条件限制
3. 游泳课需要自备泳衣泳镜
4. 运动服装和鞋子要合适
