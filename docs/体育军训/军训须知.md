# 军训须知

> 大一新生必经的军训，提前准备更从容

## 📅 军训时间

| 阶段 | 时间 | 说明 |
|------|------|------|
| 开训 | 大一开学后 | 通常在9月初 |
| 时长 | 2-3周 | 具体以学校安排为准 |
| 结训 | 军训结束 | 有汇报表演 |

- [ ] 运动鞋（舒适透气）

## 💡 军训技巧

### 站军姿
- 两脚跟并拢，两脚尖分开约60度
- 两腿挺直，小腹微收
- 挺胸抬头，目视前方
- 身体微向前倾

### 防暑降温
- 多喝水，少量多次
- 休息时找阴凉处
- 感觉不适及时报告
- 准备藿香正气水

### 体能储备
- 军训前一周开始锻炼
- 早睡早起，调整作息
- 饮食清淡，避免油腻

## ⚠️ 注意事项

1. **身体不适要报告**：不要硬撑，安全第一
2. **遵守纪律**：服从教官指挥
3. **团结同学**：军训是增进友谊的好机会
4. **保管好物品**：贵重物品随身携带

## 🎖️ 军训荣誉

- **优秀学员**：表现突出可获得荣誉证书
- **优秀方阵**：集体荣誉
- **优秀教官**：评选优秀教官
