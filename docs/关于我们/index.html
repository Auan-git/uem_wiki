关于我们

应大Wiki是什么？

应大Wiki是由应急管理大学学长学姐们共同维护的新生指南Wiki，旨在帮助每一位新生快速适应大学生活。

我们相信，一所大学的魅力不仅在于它的硬件设施，更在于一代代学生口耳相传的经验与智慧。应大Wiki就是这样一个知识共享的平台。

我们的目标

  • 建立一个完整、准确且中立的应大百科全书
  • 覆盖从入学到毕业的方方面面信息
  • 让每一位同学都能在这里找到需要的答案
  • 持续更新，保持信息的时效性

内容板块

  • 学校概览 - 了解应大的基本信息和燕郊特色
  • 入学指南 - 来校路线、报到流程、军训须知
  • 选课指南 - 选课流程、推荐课程、时间安排
  • 学分绩点 - 学分要求、绩点计算、毕业条件
  • 校园生活 - 宿舍、食堂、交通、体测等生活信息
  • 友情链接 - 学校官网、教务处等实用链接

如何参与

应大Wiki是一个开放的协作项目，欢迎每一位同学参与贡献：

  • 在文章下方评论区提出建议或纠正错误
  • 通过 GitHub 提交新的内容
  • 分享你的经验和见解

联系方式

如有任何问题或建议，欢迎通过以下方式联系我们：

  • GitHub Issues: 提交问题
  • 评论区：在任意文章下方留言
