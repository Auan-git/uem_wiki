    关于我们

    应大Wiki是什么？

    应大Wiki是面向应急管理大学学生的Wiki（百科）站点，不断收录了校园生活中的常用信息。

    本站是非官方站点，不隶属于应急管理大学或其附属组织。

    站点可能包含与应急管理大学相关的条目或内容，但这并不代表本站与应急管理大学以及其校内任何组织存在隶属关系。

    由于信息的维护需要时间和精力，本站信息的更新存在滞后性。

    本站内容出现数据/描述/观点与学校官方存在冲突时，请以官方描述为准。

    应大Wiki的目的是什么？

    建立一个完整、准确且中立的应大百科全书。
