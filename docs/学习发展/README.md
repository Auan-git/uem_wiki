# 📚 学习发展

## 🎓 奖学金

应大是部委大学，相应地各类奖学金会很多，同类型奖学金一般会多于同水平的高校，而且贫困补助也会多于一般的学校。

### 重要提醒
- 奖学金不是你大学的全部
- 贫困补助不是你占便宜的工具

### 关于绩点和奖学金的思考

在社会上，你在大学中取得的一切成绩都一文不值，如果你不是真的需要靠奖学金维持学业，那么请不要把它当成唯一目标。

应大的期末考试相对较简单，所以只要期末认真预习，便可以取得一个相对较高的成绩。

**你的大学，不是用来"熬"绩点的。**

大学的意义，是让你学会对以往深信不疑的规则进行反思——包括你现在所处的评价体系本身。

### 挂科的影响

别挂科！挂科这些真的全扯淡！！！

- 挂科需要重修
- 影响奖学金评定
- 影响入党、评优评先
- 严重者影响毕业

## 📝 四六级考试

你要问我大学期间最重要的考试是什么，我的答案是四六级考试。

### 考试时间
大学英语四/六级考试于每年6月份和12月份举行。

### 报考资格
大部分新生在大一第二学期6月份会参加四级考试，如果通过将于下一学期12月参加六级考试。学校每年也会根据新生的高考英语成绩，取一部分人在大一上报名。

### 考试用品
- **听力耳机**：大学开学会有很多人卖，注意试听、检查质量。大学之后的所有英语期末考试和四六级考试都需要使用该耳机。
- 一卡通、涂卡铅笔、橡皮、黑色碳素笔

## 🏃 体育课

我校体育课种类繁多，包括：篮/排/足/乒/网/匹克各种球类、武术、拳击、跆拳道、街舞、体育舞蹈、轮滑、健身健美、体适能、羽毛球、攀岩与素质拓展以及其他共二十余种课程。

体育课是新生第一次通过教务网络管理系统选课。新生可根据自身的兴趣爱好选择喜欢的课程。

室外课会在大一下组织上三节游泳课，地点是华科游泳池。学校统一购买泳帽，下水必戴泳帽，泳裤、泳镜自己买。

## 📖 选修课

选修课分为校选课和专选课。专选课即专业选修课，大一学生不会接触到。

大一第一学期并不开设选修课，第二学期起开设。大学四年必须修够12学分校选课才能顺利毕业。

尔雅网络选修最多可以选6分，尔雅一学期最多3分，所以校选课至少得选3分。

选修课有数十种不同的种类，涵盖各类知识，根据自己兴趣爱好来选择。大学的选课如同战争，特别多人抢，到时新生自然能领会到。
