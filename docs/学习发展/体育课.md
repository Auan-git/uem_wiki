# 🏃 体育课

## 课程概述

上课方式、分班方式同样不同其他课程的课程还有体育课。

## 课程种类

我校体育课种类繁多，包括：
- 篮/排/足/乒/网/匹克各种球类
- 武术
- 拳击
- 跆拳道
- 街舞
- 体育舞蹈
- 轮滑
- 健身健美
- 体适能
- 羽毛球
- 攀岩与素质拓展
- 其他共二十余种课程（应有竟有）

## 选课时间

体育课是新生第一次通过教务网络管理系统选课。新生可根据自身的兴趣爱好选择喜欢的课程。

## 游泳课

室外课会在大一下组织上三节游泳课，地点是华科游泳池。学校统一购买泳帽，下水必戴泳帽，泳裤、泳镜自己买。

## 注意事项

1. **选课要趁早**：体育课名额有限，热门课程很快被选完
2. **了解课程内容**：不同课程考核标准不同
3. **准备装备**：根据选择的课程准备相应的运动装备
4. **注意安全**：运动时注意安全，避免受伤

## 体测要求

体测是大学体育的重要组成部分，具体要求请参考[体测要求](../体育军训/体测要求.md)页面。
