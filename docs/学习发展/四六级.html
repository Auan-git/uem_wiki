📝 四六级考试

考试概述

你要问我大学期间最重要的考试是什么，我的答案是四六级考试。

考试时间

大学英语四/六级考试于每年6月份和12月份举行。

报考资格

  • 大部分新生在大一第二学期6月份会参加四级考试
  • 如果通过将于下一学期12月参加六级考试
  • 如果不过，谢谢参与再接再厉
  • 学校每年也会根据新生的高考英语成绩，取一部分人在大一上报名

备考建议

如果你英语分确实很高，不要在假期丢掉你的英语，四六级只有第一次和第无数次。

考试用品

听力耳机

英语考试的听力考试需要用听力耳机。听力耳机相当于戴在头上的收音机（有的耳机能做收音机用），收听各个教学楼的播音信号。

关于耳机大学开学会有很多人卖，注意试听、检查质量，以免耽误考试。大学之后的所有英语期末考试和四六级考试都需要使用该耳机。大部分耳机使用五号电池。

其他用品

  • 一卡通
  • 涂卡铅笔
  • 橡皮
  • 黑色碳素笔

考试技巧

  1. 听力：提前阅读选项，预测内容
  2. 阅读：先看题目，再读文章
  3. 写作：背诵模板，注意字数
  4. 翻译：注意时态和语态

常见问题

Q：四六级可以刷分吗？

A：可以，但建议尽早通过，不要拖到大四。

Q：四六级证书丢了怎么办？

A：可以申请补办成绩证明。

Q：四六级多少分算过？

A：一般425分以上算通过。
