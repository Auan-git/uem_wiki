## 奖学金

应大是部委大学，各类奖学金会很多，同类型奖学金一般会多于同水平的高校，贫困补助也会多于一般的学校。

**重要提醒**：奖学金不是你大学的全部，贫困补助不是你占便宜的工具。

应大的期末考试相对较简单，只要期末认真预习，便可以取得一个相对较高的成绩。**你的大学，不是用来"熬"绩点的。**

大学的意义，是让你学会对以往深信不疑的规则进行反思——包括你现在所处的评价体系本身。

### 挂科的影响
- 挂科需要重修
- 影响奖学金评定
- 影响入党、评优评先
- 严重者影响毕业

## 四六级考试

大学英语四/六级考试于每年6月份和12月份举行。大部分新生在大一第二学期6月份会参加四级考试。

### 考试用品
- **听力耳机**：大学开学会有很多人卖，注意试听、检查质量。大部分耳机使用五号电池。
- 一卡通、涂卡铅笔、橡皮、黑色碳素笔

## 选修课

大一第一学期并不开设选修课，第二学期起开设。大学四年必须修够12学分校选课才能顺利毕业。

尔雅网络选修最多可以选6分，尔雅一学期最多3分，所以校选课至少得选3分。

选修课有数十种不同的种类，涵盖各类知识，根据自己兴趣爱好来选择。大学的选课如同战争，特别多人抢，到时新生自然能领会到。
