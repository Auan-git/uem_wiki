## 💡 重要提示

1. **学分是基础**：修满规定学分才能毕业
2. **绩点很重要**：影响保研、奖学金、出国等
3. **规划要趁早**：从大一开始就重视学分和绩点
4. **及时查询**：每学期末查看成绩单，发现问题及时解决
