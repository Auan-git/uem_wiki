# 学分要求

> 本文介绍毕业所需的学分要求（具体以学校最新规定为准）

## 📊 学分构成

| 类别 | 学分要求 | 说明 |
|------|----------|------|
| 公共必修课 | ~40 学分 | 思政、英语、体育等 |
| 专业必修课 | ~50 学分 | 专业核心课程 |
| 专业选修课 | ~20 学分 | 专业方向课程 |
| 公共选修课 | ~10 学分 | 跨专业选修 |
| 实践环节 | ~20 学分 | 实习、毕设等 |
| **总计** | **~140 学分** | 具体以学校最新规定为准 |

## 📋 各学期建议学分

| 学期 | 建议学分 | 说明 |
|------|----------|------|
| 大一上 | 20-25 | 适应期，不宜过多 |
| 大一下 | 22-27 | 逐渐增加 |
| 大二上 | 25-30 | 专业课增加 |
| 大二下 | 25-30 | 保持稳定 |
| 大三上 | 20-25 | 开始考虑方向 |
| 大三下 | 15-20 | 准备实习/考研 |
| 大四上 | 10-15 | 毕设/实习 |
| 大四下 | 5-10 | 毕业冲刺 |

## 💡 学分规划建议

1. **均匀分布**：不要把课程都堆在一个学期
2. **难易搭配**：每个学期搭配难度不同的课程
3. **预留空间**：为选修课和兴趣课程留出空间
4. **及时补修**：如果有挂科，及时补修

## ⚠️ 注意事项

- 每学期最多选 30 学分（以学校最新规定为准）
- 挂科需要补修，影响毕业时间
- 转专业可能需要补修前专业课程
