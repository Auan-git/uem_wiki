# 绩点计算

> 绩点是衡量学习成绩的重要指标，影响保研、奖学金、出国等

## 绩点计算公式

### 标准算法

```
GPA = Σ(课程学分 × 课程绩点) / Σ课程学分
```

### 等级对应表

| 等级 | 分数范围 | 绩点 |
|------|----------|------|
| A+ | 95-100 | 4.3 |
| A | 90-94 | 4.0 |
| A- | 85-89 | 3.7 |
| B+ | 82-84 | 3.3 |
| B | 78-81 | 3.0 |
| B- | 75-77 | 2.7 |
| C+ | 72-74 | 2.3 |
| C | 68-71 | 2.0 |
| C- | 65-67 | 1.7 |
| D | 60-64 | 1.0 |
| F | <60 | 0 |

> 注：不同学校可能有差异，请以学校规定为准

## 计算示例

假设你选了以下课程：

| 课程 | 学分 | 成绩 | 绩点 |
|------|------|------|------|
| 高等数学 | 4 | 85 | 3.7 |
| 大学英语 | 3 | 90 | 4.0 |
| 程序设计 | 3 | 82 | 3.3 |

```
GPA = (4×3.7 + 3×4.0 + 3×3.3) / (4+3+3)
    = (14.8 + 12.0 + 9.9) / 10
    = 36.7 / 10
    = 3.67
```

## 绩点提升建议

1. **重课要重视**：学分高的课程对绩点影响大
2. **不要偏科**：每门课都要认真对待
3. **及时补救**：如果期中成绩不理想，期末要加把劲
4. **利用补考**：如果有挂科，及时补考

## 注意事项

- 绩点是累积计算的，每门课都很重要
- 重修成绩会覆盖原成绩（具体以学校规定为准）
- 保研、出国通常要求 GPA 3.5 以上
