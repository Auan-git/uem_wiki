# 选修课

## 选修课分类

选修课分为校选课和专选课。专选课即专业选修课，大一学生不会接触到，不作赘述。以下所说的选修课均是校选课。

## 开课时间

关于选修课，大一第一学期并不开设选修课，第二学期起开设。

## 学分要求

大学四年必须修够12学分校选课才能顺利毕业。关于学分，开学自己查看学生手册了解相关常识。

### 尔雅网络选修
- 尔雅网络选修最多可以选6分
- 尔雅一学期最多3分
- 所以校选课至少得选3分

## 课程种类

选修课有数十种不同的种类，涵盖各类知识，根据自己兴趣爱好来选择。如果选得到的话。

## 选课建议

1. **提前规划**：了解自己需要修够多少学分
2. **合理安排**：不要选太多，保证质量
3. **兴趣优先**：选择自己感兴趣的课程
4. **时间管理**：注意课程时间冲突

## 选课技巧

大学的选课如同战争，特别多人抢，到时新生自然能领会到。

### 抢课攻略
1. 提前准备好选课系统
2. 选课开始时立即行动
3. 准备好备选课程
4. 不要只盯着热门课程

## 常见问题

**Q：选修课可以退选吗？**
A：一般有退选时间，具体看教务系统通知。

**Q：选修课挂科怎么办？**
A：需要重修，建议认真对待。

**Q：尔雅课程是什么？**
A：网络选修课，可以在线学习，比较灵活。
