学校简介

应急管理大学是中国应急管理部直属的高水平应用研究型大学，由华北科技学院与防灾科技学院合并组建而成，位于河北省三河市燕郊国家高新技术开发区，毗邻北京城市副中心。

应急管理大学是应急管理部主管的公办普通高等学校，也是国内第一所以"应急管理"命名的大学。学校的历史可追溯到1950年成立的中央燃料工业部干部学校（华北科技学院前身）和1975年成立的国家地震局天水地震学校（防灾科技学院前身），在安全生产与防震减灾领域积淀深厚。

学校占地面积约1273.68亩，建筑面积66.47万平方米，现有全职专任教师约1600余人，全日制在校生约2.7万余人。学校教学科研仪器设备总值达9.2亿元，馆藏纸质图书287.7万册，电子图书158.7万种。

它是什么层次？

应大是一所普通本科院校。虽然是由两个二本大学（华北科技学院和防灾科技学院）合并而来，但二本从来都不意味着学风差。任课老师都是硕士博士甚至于博士后。同时在大一期间，有强制制度来督促学生上晚自习。

它有什么特殊之处？

应急管理大学是中央部委（应急管理部）直属院校。部属院校发展潜力大，应急管理部和教育部是同等的部门。这里优越于河北省内其他高校的是它有充足的资金和硬件来支持你努力学习。

燕郊，一个神奇的地方

燕郊位于北京东侧，行政区域属于河北廊坊市，离廊坊却70多公里。然而它与北京仅有一河（潮白河为界，西岸是北京通州，东岸是河北燕郊）之隔，距离国贸有且仅有30公里。

它名字是北京的，地界是河北廊坊的，历史是天津蓟县的，网购是北京通州的，公交是北京八方达，客车是河北客运。它被称谓"睡城"，住在此地的多为首都上班的外地人，30万的流动人口，过着中国罕见的"双城生活"。

学校周边

学校周边很多大型购物广场如：天洋城广场、新世界百货（内含沃尔玛超市）、乐天玛特购物广场、物美等等。从天桥向西出发，爱民路是一条美食街，这里有来自全国各地的美食和街边小吃。

学校周边的大型购物中心里都有电影院；燕郊有燕郊公园和燕郊植物园。北京，才是燕郊最大的公园。

学校门前有811、812、818三路公交车，去北京相当方便，周六日就可以去首都玩玩。
