# 🏛️ 学生组织

## 组织概览

学生会、社团联合会、艺术团、国旗护卫队、各类社团协会及其他各类学生组织，这些都可以统一称为学生组织。

## 全校级学生组织

校团委领导下的各个组织包括校学生会、社团联合会、艺术团、国旗护卫队、校报、杂志社以及其他学生组织。

### 学生会
学生会下设办公室及各个职能部门，负责学生工作。

### 社团联合会
社团联合会亦建制俱全，负责社团工作。

### 艺术团
艺术团亦建制俱全，还包括礼仪模特队、管乐团、声乐团、TNT街舞社及其他艺术类组织。

这些是具有官方性质的学生组织，所谓"官方"，即校团委直接领导，直接目的是为学校、学生服务的组织。并不是所谓的干部、干事把自己当成"官"，如果有这种官本思想，无疑是一种拿着鸡毛当令箭的笑话。

官方组织的工作更严肃一点，因为你是公共服务者，如果工作疏忽、不负责，错误危害也不止一人，可能严重。

## 社团协会

既然有"官方"，自然也有"民间"。那么因兴趣爱好聚集在一起的各个社团协会可以归为此类。

我校社团较多，等"百团大战"的时候你就知道了，故不过多介绍。

社团有着很大的自主性，气氛也更加轻松愉快，将会有更多志同道合的朋友。报名参加各个社团的第一原则，一定是兴趣爱好，而不是抱有其他别的什么目的。社团不要一次报个7、8个，1-2个足以，否则会过多分散你的时间而得不偿失。

## 实验室

这里的实验室不是指那种做普通实验的公共实验室，指的是面向本科生开放，有固定的指导老师，固定的工位，以及一定的成熟或者不成熟的管理体制的地方，这个地方是以比赛和项目为导向的。

首先大家不要觉得我大一啥都不会，他们要不要我，去了会有相应的培养，但也不要觉得去了就能混奖。

## 院部级学生组织

院部级学生组织主要包括院团委和院学生会，当然院部不同可能还会设有其他不同的组织。

院级组织级别虽然低于校级组织，但是所谓的"实权"并不亚于甚至要超过校级组织。因为院级组织所负责的，直接是本学院的各项学生工作，接触的是本学院学生的基本工作和生活。大家低头不见抬头见，工作关系也更为紧密。

## 参加及发展

### 招新报名
新生大可不必担心招新问题，因为各个组织会穷尽所能地扩大知名度，吸引优质新生来参与其组织。

### 入选面试
校、院级官方学生组织、大型社团协会都需要通过入选面试。面试其实并不要求新生有多强的能力，更多要求的是责任和热情，因为你们的面试官也是学生干部，从同样的阶段过来，他们更愿意接纳认真负责、有干劲儿的新生。

## 班干部

别拿班干部不当干部。所有的学生干部里，班干部最重要，它可不是芝麻官。

班干部中最重要的两个职位就是班长和团支书。两人协同管理全班事务，包括组织班集体活动、下达并执行各类通知、评选助学金及入党名额的分配等众多工作。

在大学，你可能一年见不到几次班主任，一个月见不到几次辅导员，而班长和团支书就成了你们最直接的两大家长。

班委通常还包括其他成员，如学习委员、生活委员、体育委员、组织委员、宣传委员、心理委员以及各个宿舍长。

班委是最小的学生干部群体，但学生组织往往是越小越精干，班委就是最精干、最高效也是最锻炼的学生干部职位。新生如有意愿，可以积极参加竞选。

## 入党、评优评先

里面门道和技巧很多，但是有一点就是不会亏待优秀的人。所以，提高自己的综合能力及素质很重要。

入党需要经过以下程序：参加青马班—被选为入党积极分子—被列入下年度预备党员发展计划—准备政审材料及函调材料—参加党课学习—发展成为预备党员—预备期满转为正式党员。

这个周期需要多长呢，如果大一的第二学期被评选为积极分子，那么如果一路顺风最早你将于大三第二学期被发展成为正式党员。

评优评先每年5月4日左右。
