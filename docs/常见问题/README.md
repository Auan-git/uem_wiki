# ❓ 常见问题

新生常见问题解答，帮你快速适应大学生活。

## 📋 问题分类

### 学业相关

**Q: 大学英语四级什么时候考？**
A: 通常在大一下学期或大二上学期可以报考，具体以学校通知为准。

**Q: 挂科了怎么办？**
A: 及时补修，补修通过后成绩会覆盖原成绩。具体以学校规定为准。

**Q: 如何转专业？**
A: 通常在大一下学期可以申请，需要满足一定条件（如绩点要求）。具体流程咨询教务处。

**Q: 保研需要什么条件？**
A: 通常需要：绩点排名前列、无挂科记录、英语成绩达标、科研/竞赛经历等。

### 生活相关

**Q: 校园卡丢了怎么办？**
A: 立即挂失（线上或线下），然后补办。挂失前的消费无法追回。

**Q: 快递怎么收？**
A: 通常在快递站凭取件码领取，或送到宿舍楼下。

**Q: 宿舍可以装空调吗？**
A: 以学校规定为准，部分宿舍可能已有空调。

**Q: 洗澡怎么解决？**
A: 部分宿舍有独立卫浴，部分需要去公共浴室。

### 军训相关

**Q: 军训可以请假吗？**
A: 因伤病不能参加的，需要提前申请免测，提供医院证明。

**Q: 军训穿什么鞋？**
A: 穿舒适的运动鞋，不要穿新鞋（容易磨脚）。

**Q: 军训很累吗？**
A: 有一定强度，但会循序渐进。注意防暑，及时休息。
