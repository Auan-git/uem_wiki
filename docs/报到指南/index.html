📋 报到指南

报到日期及流程

粗谈

在通知书下发之前，很多同学会问什么时候报到。

一个比较靠谱的规律是这样的：学长学姐们正式上课的第一周的周六和周日，就是正式迎新的两天，但正式迎新前一天的下午就已经可以顺利报到并办理、正常的入学手续了。形象点：假如新生正式报到日期为8月31日和9月1日左右，具体看通知书，而如果新生于8月30日来，下午可能需要在外住宿（也可能直接进校，具体看安排）。

报到的具体流程：现场会有接待新生的工作人员（请认准每个工作人员的工作牌）来带着新生逐一完成。

报到需要带

  • 录取通知书
  • 钱
  • 换洗衣物
  • 各类材料
  • 贫困生证明等（需要的同学带）
  • 常用药品
  • 旧毛巾（打扫宿舍床铺）

每个学院都会有志愿者去接，他们会有志愿者马甲，胸牌，袖标其中之一，所以不要害怕，也不要说他们嫌我烦怎末的，既然选择当志愿者，大家都是抱着为大家服务的想法来的，或者你也可以在新生群里联系一个学长或者学姐，他们会帮助你的。

细节

报到一定要注意最后期限问题，若是超时不报到，可能无法取得学籍。最后期限等问题应该在你们的录取通知书中有详细的说明。

同时录取通知书中可能含有中国银行卡等附件，其中特别说明的是中行卡，务必保管好，大学四年的奖学金、助学金、学费书费缴纳都是通过这张卡，丢了会十分麻烦。（不含的也可以开学办一张，当地也行）。

中行卡丢了先补办，三食堂西餐厅旁，有营业厅。

助学贷款和贫困助学金

办理助学贷款和准备申请贫困助学金相信不必提醒也知道，办理方法在通知书里。暑假期间把各类证明和材料预备好。大一上学期好办理贫困生补助，入选比较容易。（还是那句话，咱学校是部委大学，有钱）

生活用品

被子、被罩、枕头、枕巾、枕套、床单、蚊帐，学校附近可以购买，这些简单的床上用品不用千里迢迢地从家里带来。或者可以选择邮寄，不过开学时候的快递站，人会非常的多。

大学是有校服的，21届开始的是全蓝色。不过不是天天穿，只有大一军训和学校重要仪式的时候穿，建议带上几张1寸照片，在新生报到和社团招新都用得到。初来乍到、人生地不熟的话来学校准备这些可能会麻烦。

凭借录取通知书可于本地火车站购买优惠火车票（坐票半价，卧铺75折，高铁动车75折），尤其是路途遥远的同学。

建议找个靠谱的学长学姐，最好是老乡或者同一院系的学长学姐，在假期间做做私人定制的顾问和开学以后的向导，这样最稳妥。

军训

军训还是有很多惊喜的。

军训的开始时间为报到3-5天后开始，这3-5天新生将要开各种各样的新生大会，虽然听起来感到枯燥无聊，但毕竟也是刚刚踏入大学校园，还是会有新鲜感的，当然这也是必要环节，逃不过的。

军训时间两周左右。期间的最后几天的某天晚上会有迎新晚会，可能是枯燥的军训生活中比较有意思的一晚。最后一天会举行阅兵。

军训期间或者军训结束会有百团大战，到时候你可以找一找你感兴趣的社团，会很有意思。(就是学校不允许百团大战时男扮女装，不好玩了)

军训的主要内容是队型排列和动作、内务整理、紧急疏散、国防知识讲座等无聊内容，枯燥的生活中拉军歌可能就变成有意思的消遣了。

军训半个月虽然枯燥，但是经历以后与教官分别也是良多感慨。你们的教官有很多比你们大不了多少。
