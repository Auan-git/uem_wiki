# 🚌 来校交通

由于学校在燕郊，而燕郊在北京周边，所以最方便的来校路线是先到达北京后，乘坐地铁公交到燕郊，当然你也可以直接坐到燕郊站，当然要根据你的出发地来确定接下来的路线。

## 交通方式概览

| 方式 | 推荐指数 | 说明 |
|------|----------|------|
| 🚗 自驾 | ⭐⭐⭐⭐ | 最方便，需办进京证 |
| 🚄 高铁/火车 | ⭐⭐⭐⭐⭐ | 最常用，转乘812路 |
| ✈️ 飞机 | ⭐⭐⭐ | 到首都机场较近 |
| 🚌 大巴 | ⭐⭐⭐ | 北京各客运站可转乘 |

## 温馨提示

- 凭借录取通知书可于本地火车站购买优惠火车票（坐票半价，卧铺75折，高铁动车75折）
- 北京市公交车均为北京牌照，请到有站牌的站点上车
- 建议下载高德地图或百度地图，实时导航最准确
