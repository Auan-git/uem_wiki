    心理健康

    写在前面

    写这一章之前，我想先说一句：如果你正在经历情绪的低谷，这不是你的错，你也不是一个人。

    大学是一个很特殊的阶段。你离开了熟悉的高中环境和家庭庇护，被扔进一个完全陌生的系统里。周围的人看起来都很厉害，朋友圈里大家都在晒精彩的生活，而你可能在宿舍床上翻来覆去睡不着，想家、迷茫、焦虑，甚至说不清自己在难受什么。

    这太正常了。只是很少有人愿意公开聊这些。

    你可能遇到的心理状态（都是正常的）

    以下是应大学长学姐们真实经历过的事情，看看有没有你的影子：

    落差感

    高中时你是班里的尖子，到了这里发现身边全是差不多水平的人，甚至有人比你强很多。突然从"优秀"变成"普通"，那种失重感需要时间消化。

    无意义感

    按部就班上课、吃饭、睡觉，不知道自己在学什么、将来要干什么。特别是被调剂到一个不了解的专业时，会怀疑"我在这里干什么"。

    孤独感

    宿舍里大家各玩各的手机，班级同学除了上课见一面几乎没有交集。你以为大学会有很多朋友，结果发现认识的人很多，能说心里话的很少。

    燕郊特供版"被困住"的感觉

    想去北京玩又嫌远，待在燕郊又觉得无聊，看着朋友圈里在北上广深上学的同学光鲜亮丽，感觉自己被"困"在这个河北小镇里。

    季节性情绪低落

    北方冬天又冷又干，下午四点多天就黑了，加上期末压力，很容易觉得整个人都不好了。

    学校的心理支持资源（真的有，而且是免费的）

    首先明确一点：应急管理大学有心理咨询中心，而且是免费的、保密的。这不是只有"心理有病"才能去的地方，任何让你不舒服的事情——失恋、学业压力、人际矛盾、家庭问题——都可以去找老师聊聊。

    位置

    具体位置请查阅新生手册或询问辅导员，通常在学生活动中心或校医院附近。（不同校区位置不同，入学后问一句就知）

    预约方式

    1. 邮箱预约

    发邮件至 ydxlzx2026@163.com（随着年份的变化年份数字可能会变，具体看通知）

    邮件主题需标明"心理咨询预约+学院+班级+学号+姓名"。

    2. 邮件内容

    可以用1-2句话简要说明想要咨询的问题，以及可以做心理咨询的时间段。

    请在工作日8:00-11:30，14:00-17:30进行预约。

    咨询时间

    每周一至周五：

    • 8:30-11:00
    • 14:30-17:00
    • 18:00-20:00

    保密原则

    咨询内容不会被透露给辅导员、家长或同学，除非涉及自伤/伤人风险。所以不用害怕"被记录档案"，咨询为50分钟。

    费用

    完全免费。这是你交了学费的一部分，不用白不用。

    自我调节的一些办法

    在预约咨询之前，或者日常情绪小波动时，这些方法可以帮你撑住：

    1. 去北京暴走

    情绪堵得慌的时候，坐812去国贸，从国贸沿着长安街往西走。走累了就坐地铁回来。身体的疲惫有时能清空大脑的垃圾。成本：来回公交费不到10块。

    2. 去操场跑圈

    不是为了减肥，是为了让身体动起来。中区和西区，北二区都有操场，晚上人不少，跑完洗个澡，睡眠质量会好很多。

    3. 写下来，哪怕只是碎片

    手机备忘录里开一个"情绪垃圾桶"文件夹。难受的时候把脑子里乱七八糟的想法全打出来，不用管逻辑和文笔。打完你可能会发现，事情在纸上比在脑子里清晰得多。

    4. 找"第三空间"

    宿舍待不下去、图书馆又太安静的时候，去校门口的奶茶店、麦当劳，或者燕郊公园的长椅上坐一会儿。换一个物理环境，有时能换一种心理状态。

    5. 晒早晨的太阳

    如果你熬夜后第二天情绪特别差，试着逼自己八点前起床，去阳台或楼下待十分钟。阳光对视交叉上核的刺激（不用懂这个词），能实实在在地调节你的生物钟和情绪。

    关于"别人"和"比较"

    你在朋友圈、小红书、抖音上看到的那些光鲜亮丽的大学生活，大概率是精心剪辑过的预告片，不是正片。

    应大也一样。有人拿国奖，有人保研985，有人创业月入过万。但你不知道的是——那个国奖大佬可能也在深夜崩溃大哭过，那个保研的学长可能也挂过科，那个创业的同学可能欠了一屁股债。

    不要用别人的高光时刻，来对比自己的日常状态。这对自己不公平。

    如果你发现身边人状态不对

    这一节很短，但很重要。

    如果你发现室友/朋友突然变得沉默寡言、长期失眠、拒绝社交、在社交平台发一些告别性质的内容，请不要觉得"多一事不如少一事"。你可以做这些事：

    1. 直接问一句："你最近是不是不太开心？需要聊聊吗？"
    2. 不要评判，不要给建议，先听。
    3. 如果你觉得情况超出你的能力范围，建议TA去心理咨询中心，或者陪TA去。
    4. 如果情况紧急（有自伤风险），立刻联系辅导员或拨打学校保卫处电话。这不是"出卖朋友"，这是救命。

    写在最后

    在应大的四年，你可能会经历很多次"不想活了"的瞬间——考试周通宵复习到崩溃、失恋后觉得世界塌了、被各种通知和表格折腾得想骂人。

    但也会有很多"活着真好"的瞬间——凌晨四点从实验室出来看到日出、和室友在爱民路撸串吹牛、在北京看完展坐着812晃晃悠悠回燕郊、收到offer时手抖着给家里打电话。

    情绪像燕郊的天气，有时雾霾重重，有时风和日丽。雾霾会散的，风会来的。

    如果你现在正在黑暗里，请记住：学校的心理咨询中心有一盏灯为你亮着，免费的那种。
