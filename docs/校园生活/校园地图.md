## 校园交通

### 步行路线
- 宿舍 → 教学楼：约10分钟
- 宿舍 → 食堂：约5分钟
- 宿舍 → 图书馆：约15分钟

### 校园巴士
- 运营时间：7:00-22:00
- 站点：宿舍区、教学楼、图书馆
- 票价：免费/1元（以学校规定为准）

## 校园小贴士

1. **新生报到**：先熟悉校园环境
2. **下载地图**：可以用百度/高德地图导航
3. **记住路线**：记住常用路线
4. **问路技巧**：问保安、宿管、学长学姐
