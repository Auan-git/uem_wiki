# 🌆 燕郊生活

## 燕郊，一个神奇的地方

### 官方回答

燕郊距北京市中心天安门35 公里，距空港首都机场25 公里（不确定起点从哪开始），距天津港120 公里，可承东启西、经纬南北，提供融入京津、俯仰全国、接轨世界的绝佳平台。（河北小样）

### 学生自己回答

燕郊位于北京东侧，行政区域属于河北廊坊市，离廊坊却70多公里。然而它与北京仅有一河（潮白河为界，西岸是北京通州，东岸是河北燕郊）之隔，距离国贸有且仅有30公里，由于行政划分和实际距离的交错，燕郊成为了一个神奇的地方——它名字是北京的，地界是河北廊坊的，历史是天津蓟县的，网购是北京通州的，公交是北京八方达，客车是河北客运，满大街几乎都是东北腔（河北小样，北三县的一部分）。

IP地址在网络信号没那么好的时候，会在北京和河北来回飘，12306 买火车票注册高校学生信息（大学生火车票优惠）你会发现自己学院被划入北京院校。

### 燕郊的大学

这里有五所大学，三所是中央部委直属，分别是应急管理大学（你未来生活的地方，应急管理部直属）、民政职业大学（民政部）、交通部管理干部学院（成人本科，交通运输部）、燕京理工学院（本科+专科）、北京经济职业技术学院（专科）。

有人说它是三不管，有人说它是三面争；有人说它是城乡结合部，有人说它是接轨世界的平台……总之，燕郊很神奇。

它被称谓"睡城"，住在此地的多为首都上班的外地人，白天在北京上班，晚上在河北过夜，30 万的流动人口，过着中国罕见的"双城生活"。如果你好奇这是如何的一番景象，欢迎早上七八点到白庙检查站来看一看，一定会让你震惊和感叹。

### 燕郊的特色

燕郊，燕郊镇，燕郊经济开发区，开发区，必然会在经济上展现出他独特的一幕。

大型楼盘修建得与北京无二的，各类高端酒店，会所，洗浴中心应有尽有，但他本质上还是一个镇，一个容纳了30多万来自于全国各地人口的镇，街道上奔涌的三轮车、出租车和小贩，喇叭、叫卖声比首都更响。（欢迎你到凌晨四点的小张各庄看一看）

这里有专家、大师，更不乏农民工兄弟们；这里有高楼大厦，同样有矮屋陋巷；你可以左手拿着星巴克、右手攥着羊肉串……

关于燕郊的神奇，几天几夜也说不完。你可以在这里创造传说，也可以变成一位待留四年的江湖过客。这四年，这个神奇的地方，一定会给你打上一块不一样的烙印。

燕郊，是个神奇的地方。

### 学校周边

正如上面所说，燕郊的行政级别是一个镇，有的同学就要问了，那我们学校周边是燕郊的大型楼盘呢？还是燕郊的村庄呢？

我们的学校东边紧挨小张庄村、西边紧挨中赵甫村——所以学校差不多是地处农村咯~

这你就大错特错了。燕郊是个神奇的地方

天子脚下，御驾行宫。换句话说，首都的邻居能差到哪儿去呢。

学校周边很多大型购物广场如：天洋城广场、新世界百货（内含沃尔玛超市）、乐天玛特购物广场、物美等等，距离学校都不远。当然学校内部和周边也有很多小型超市，生活用品种类充足；南门出门左拐就有一条商业步行街，也挺热闹。

从天桥向西出发，或者从北区向南出发，爱民路是一条美食街，这里有来自全国各地的美食和街边小吃，有时候，你还会看到小姐姐的绝美表演，所有这里不会让你失望，至少不必担心。

如果你谈个女朋友，没事儿想去看个电影、逛个公园，这里同样可以满足你。

学校周边的大型购物中心里都有电影院，如东星国际影城（位置在新世界百货四层）、星美国际影城、乐天玛特影城、天洋城影院、星罗影院等；如果是逛公园，燕郊有燕郊公园和燕郊植物园，其中燕郊公园就在学校南门左拐不远，两个公园都不大，跟别的城市公园相比别无二致，但正适合散步遛弯儿。

晚上超过11 点最好不要去燕郊的任何公园，晚上太晚也尽量不要出去浪，毕竟燕郊有些复杂，夜晚不一定安全。当然如果不满足于此，不要担心——

北京，才是燕郊最大的公园。

喜欢社交、忙碌于朋友聚会，燕郊也有很多休闲场所，水吧、台球厅、KTV都不少。不要怕钱花不出去，想玩高端的，华堂国际高尔夫俱乐部欢迎你。

应大周边的商业发达程度并不亚于一些中小型城市，你如果嫌弃中小型城市不够发达，那坐趟812 或811 或818 没事儿去北京转转也不是问题，当然，骑自行车也可以，有同学试过，挺不错的体验。

当然，你想了解更加详细的区位，欢迎打开高德地图，或者联系学长，他们会知无不言的。
