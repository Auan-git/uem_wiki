## 💡 选课小贴士

1. **提前规划**：在选课前一周就开始研究课程
2. **多看评价**：参考往届学长学姐的课程评价
3. **合理搭配**：注意课程难度和时间的搭配
4. **备选方案**：准备好备选课程，防止热门课选不上

## ⚠️ 常见问题

- **Q: 选课系统什么时候开放？**
  A: 通常在开学前一周，请关注教务处通知

- **Q: 选课后可以退课吗？**
  A: 开学后两周内可以退课，请及时操作

- **Q: 如何查看课程评价？**
  A: 可以在本Wiki的评论区查看往届学长学姐的评价
