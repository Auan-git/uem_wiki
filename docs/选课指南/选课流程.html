选课流程

🌐 教务系统登录

方式一：网页登录

  1. 登录学校官网 https://www.ncist.edu.cn/
  2. 选择「信息门户」
  3. 由学校统一登录平台登录进入办事大厅
  4. 找到「教育教学」中的「教务管理系统」
  5. 点击在线办理登入教务管理系统
  6. 在「选课」模块中「专选报名」或「选课」模块进行操作

方式二：钉钉

绑定钉钉的同学可以直接在钉钉应用中选择「教学服务」中的「专选报名」或「选课」模块进行操作。

📋 选课类型

（一）专选课报名

  • 在「专选报名」模块中操作
  • 按学生培养方案，学生可根据个人学习情况参加专选课报名
  • 课程选中不分选课时间先后，不限选课人数
  • 注意：部分 2025 级专业下学期未开设专选课，不用参加选课报名

（二）体育选项课（2025 级必修）

  • 2025 级体育选项课为必修课
  • 所有同学必须选择一门体育选项课程
  • 该课程有容量限制，选满的课程不能再选
  • 选课期间可以退课后再选别的未满课程
  • 选课结束后不再组织补选

（三）校内公共选修课

  • 校内公选课安排在周一、三、五的 9-10 节
  • 不允许冲突选课
  • 每个同学一学期可以选择 1-3 学分校内公选课

🔧 选课步骤

1. 登录选课系统

按照上述方式登录教务管理系统

2. 查看课程列表

  • 进入「选课管理」→「选课」
  • 按课程类别筛选（必修/选修/公选）
  • 查看课程详细信息（时间、地点、教师）

3. 选择课程

  1. 在搜索框输入课程名称或教师姓名
  2. 点击「选课」按钮
  3. 确认选课成功
  4. 在「已选课程」中查看

4. 确认课表

  • 进入「课表查看」确认时间无冲突
  • 打印或截图保存课表

⚠️ 选课要求

  1. 学生做好选课准备，提前检查账号是否可登录，如密码丢失，可通过绑定的手机号找回重置密码
  2. 学生在选课的过程中应遵循诚实守信、量力而行的原则，根据自身选课情况及课程数量进行选课，合理安排上课时间，避免造成课程资源的浪费
  3. 学生选课依据学生本人所在年级、专业的人才培养方案进行，所有课程一经选定，除已申请免听、免修的课程，学生本人必须参加已选课程的各项教学活动，并参加课程考核或考试
  4. 请各学院务必通知到所有学生，自行按时上网选课，不在规定时间内将无法选课，责任自负
